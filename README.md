# 🌦️ React Weather App

A stylish weather application built with **React** and **Material UI**.

## 🚀 Features
- Search for any city worldwide.
- Dynamic background images based on temperature/humidity.
- Real-time data from OpenWeatherMap API.
- Responsive design using MUI Cards.

## 🛠️ Setup Instructions
1. Clone the repo: `git clone <your-link>`
2. Install dependencies: `npm install`
3. Create a `.env` file in the root.
4. Add your API key: `VITE_API_KEY=your_key_here`
5. Start the app: `npm run dev`
